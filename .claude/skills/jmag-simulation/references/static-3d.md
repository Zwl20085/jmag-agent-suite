# 3D Static study reference (index)

The 3D Static reference is split by topic; this file keeps the old name so links and
`jmag_guide(reference="static-3d.md")` still resolve. Section numbers are unchanged.

- `static-3d-basics.md` - sections 1-7: status, coil excitation modes, step-by-step workflow, result keys,
  traps, cross-validation numbers (transformer / inductor L), what is not verified.
- `static-3d-rotating.md` - section 8 (8.1-8.9): PM machine in 3D Static, boundaries and periodic sectors,
  magnets, slit tooth coils, torque, one STEP per rotor angle, cogging mesh noise.
- `static-3d-nonlinear.md` - sections 9-10: user B-H steel, analysis control, `jcgmntr` convergence, cost,
  deep saturation, radial-flux machine with straight end windings.

Start with basics; the other two assume it.
